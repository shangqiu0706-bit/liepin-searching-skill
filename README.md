# 猎聘 Searching Skill

用于根据 JD 在猎聘上搜索、核验和整理候选人。它提供关键词扩展、公司反查、详情页证据核验和结构化分层的工作流；不包含候选人数据，也不提供猎聘账号权限。

## 安装

在已安装 Codex 的机器上运行：

```bash
git clone https://github.com/shangqiu0706-bit/liepin-searching-skill.git ~/.codex/skills/liepin-searching
```

重启 Codex 或新开任务后，可直接使用：

```text
用 $liepin-searching 帮我根据这个 JD 找人。
```

如果本机已存在同名 Skill，请先备份现有目录，或克隆到其他目录后手动合并；不要覆盖本地的案例、候选人输出或自定义迭代记录。没有 Obsidian 记忆库时可直接跳过记忆读取步骤。

## 使用方式

提供岗位目标、业务问题、优先级、地点、薪资口径、可迁移范围和交付要求即可。不要预先把薪资或复杂经历条件卡死在搜索页；Skill 会在候选人详情页完成核验。

```text
用 $liepin-searching 帮我找人。

岗位：消费者洞察负责人，base 广州
目标：支持新品、品牌定位和 GTM 决策。
优先：有甲方 CMI 经验，并能证明洞察影响过产品、品牌或商业决策。
薪资：岗位范围 35–60k/月；候选人期望只要与此区间有交集即可保留。
输出：推荐池、可沟通边界池、待验证池和剔除摘要；附详情页证据与链接。
边界：只搜索、核验和整理；不联系候选人、不查看联系方式。
```

## 协作与安全

- 每位使用者须使用自己的已授权猎聘账号；不要共享账号、Cookie、token 或联系方式。
- 不要提交候选人姓名、简历 ID、详情页 URL、联系方式、截图、搜索日志、导出文件或任何个人数据；`.gitignore` 无法保护已被提交的文件。
- 更新时保留 `SKILL.md`、`references/` 和 `agents/` 的目录结构；案例内容留在本地工作区。
